## Bluetooth (works: scan + basic connection, user-confirmed)
Three btd fixes on `ws-y-bt` (`phone/bt/btd.c`, `hci.c`, `hci.h`):
1. **Bridge loop on select()**: `/dev/btbridge` is read non-blocking every pass and the loop sleeps in
   `select()`; no restart loop when the node is missing.
2. **vayu HCI shim rules**: answers locally the commands the WCN3998 refuses or that would hurt it
   (QCA 0xFC00/0xFC0B/0xFC48 never reach the chip; 0xfd48 answered with status 0x01; supported-commands fixes).
3. **IBS wake byte fix**: hci.h had 0xFD/0xFE swapped. 0xFD = wake indication, 0xFE = sleep, 0xFC = wake ack;
   btd acks every 0xFD with 0xFC, wakes the chip before TX after a 0xFE, and never forwards IBS bytes to the host.

**Lesson (poll/POLLNVAL):** `poll()` on `/dev/btbridge` returned `POLLNVAL` at once. In XNU a cdevsw node
supports poll/kqueue only after `cdevsw_setkqueueok()` is called for its major; 1010's node does not, so
userland must use non-blocking reads + `select()` (or the kernel patch must call `cdevsw_setkqueueok`).

## Build guard
`tools-claude/localbuild/xnu.sh`: a kernel patch that does not apply now **fails the build** unless its name is in
`patch-skip-allow.txt` (the 5 patches that never applied on 13.5's xnu). No more silent skips.
